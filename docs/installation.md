# Installation

## Prerequisites

| Tool | Version | Used by |
|------|---------|---------|
| [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) | latest | Required — plugin host |
| [Git](https://git-scm.com/downloads) | 2.20+ | All skills (worktree support) |
| [GitHub CLI (`gh`)](https://github.com/cli/cli#installation) | latest | PR, ticket, release skills |
| [`jq`](https://jqlang.github.io/jq/download/) | 1.6+ | Tracker detection, worktree hooks, session hooks |
| [`uv`](https://docs.astral.sh/uv/getting-started/installation/) | latest | All Python scripts (PEP 723 shebang), worktree setup |
| [`yq` v4](https://github.com/mikefarah/yq#install) (mikefarah) | 4.x | `skill-index` (MOTD, skills menu) |

### Optional (skill-specific)

| Tool | Used by |
|------|---------|
| [PostgreSQL client (`psql`)](https://www.postgresql.org/download/) | `dev10x-db:db-psql` — database queries |
| Linux: [`libsecret` (`secret-tool`)](https://gitlab.gnome.org/GNOME/libsecret); macOS: Keychain (built-in) | Keyring lookups for DB DSNs, Slack tokens, Linear API keys |
| [`ffmpeg`](https://ffmpeg.org/download.html) | `dev10x-qa:qa-self` — video evidence conversion |
| [ImageMagick](https://imagemagick.org/script/download.php) (`convert`) | `dev10x-qa:qa-self` — screenshot conversion |
| [Playwright](https://playwright.dev/python/docs/intro#installing-playwright) | `dev10x-qa:playwright` — browser QA (auto-installed via `uv`) |
| [`bump-my-version`](https://github.com/callowayproject/bump-my-version#installation) | `bin/release.sh` — plugin releases |

> **Python dependencies** are handled automatically. Scripts use
> [PEP 723](https://peps.python.org/pep-0723/) inline metadata so `uv`
> resolves packages like `slack_sdk`, `pyyaml`, and `requests` at
> runtime — no manual `pip install` needed.

## Option A: Marketplace install (recommended)

Run these commands in your shell (not inside a Claude Code session —
the in-session `/plugin` slash commands are unreliable for install):

```bash
claude plugin marketplace add Dev10x-Guru/dev10x-claude
claude plugin install dev10x@Dev10x-Guru
```

`dev10x` is the core every other Dev10x plugin depends on.
It ships both MCP servers (`cli` and `db`), the safety hooks, and the
setup, permission, friction and playbook skills (`afk`, `ask`,
`onboarding`, `friction-setup`, `upgrade-cleanup`, `plugin-doctor`,
`plugin-maintenance`, `playbook` and the rest).
The coding skills (commits, PRs, branch hygiene, code review) ship as
`dev10x-coding`, described below.
`/dev10x:plugin-doctor` reports a satellite enabled while `dev10x` is
turned off, and permission rules that still name a moved skill by its
old `dev10x:` name.

The self-QA walkthrough skills (`qa-self`, `playwright`, `qa-publish`,
`tts`, `yt-upload`, `review-pack`) ship as a separate plugin. Install it
where you record walkthroughs; it brings `dev10x` with it:

```bash
claude plugin install dev10x-qa@Dev10x-Guru
```

The read-only infrastructure skills (`aws-vault`, `k8s`) ship as
`dev10x-infra`. Install it where you inspect AWS secrets or Kubernetes
clusters; it also brings `dev10x` with it:

```bash
claude plugin install dev10x-infra@Dev10x-Guru
```

The database skills (`db`, `db-psql`, `sql-handoff`) ship as
`dev10x-db`. Install it where you query databases; it also brings
`dev10x` with it. The `mcp__plugin_dev10x_db__query` tool stays in
`dev10x` under its old name, but it runs the `db.sh` script that
`dev10x-db` ships, so queries need both plugins:

```bash
claude plugin install dev10x-db@Dev10x-Guru
```

The communication skills (`slack`, `slack-setup`, `gchat`, `gog`, `bus`,
`overwatch`, `voice-channel`) ship as `dev10x-comm`.
Install it where you post to Slack or Google Chat, or link sessions over
the local bus; it also brings `dev10x` with it.
The Chat bus MCP tools, the `dev10x skill notify` commands and the
Overwatch hook stay in `dev10x` under their old names.
`slack-review-request` and `gchat-review-request` ship in
`dev10x-coding` and hand the post to `dev10x-comm:slack` / `dev10x-comm:gchat`, so a review
notification needs both plugins:

```bash
claude plugin install dev10x-comm@Dev10x-Guru
```

The skill management skills (`skill-create`, `skill-audit`,
`skill-audit-queue`, `audit-file`, `skill-index`, `context-audit`,
`memory-maintenance`) ship as `dev10x-teach`.
Install it where you author or audit skills; it also brings `dev10x`
with it.
The session-audit and `generate_skill_index` MCP tools stay in `dev10x`
under their old names and run the scripts from `dev10x-teach`, so they
need both plugins.
SessionStart shows `~/.claude/SKILLS.md` whether or not `dev10x-teach`
is installed; it is only regenerated by `dev10x-teach:skill-index`:

```bash
claude plugin install dev10x-teach@Dev10x-Guru
```

The task management skills (`session-tasks`, `session-wrap-up`,
`plan-sync`, `park`, `park-discover`, `park-todo`, `park-remind`,
`reflect`) ship as `dev10x-tasks`.
Install it where you park deferred work, wrap up sessions or reflect
lessons into a vault; it also brings `dev10x` with it.
The task hooks (`task-guard`, `task-plan-sync`), the `task_index_*` and
`plan_sync_*` MCP tools and the `dev10x skill reflect` command stay in
`dev10x` under their old names, so the Stop hook keeps reading the task
list whether or not `dev10x-tasks` is installed:

```bash
claude plugin install dev10x-tasks@Dev10x-Guru
```

The ticket and scoping skills (`ticket-create`, `ticket-jtbd`,
`ticket-scope`, `jira`, `linear`, `scope`, `project-scope`,
`project-audit`, `estimate`, `jtbd`, `ddd`, `spec-sync`, `spec-update`,
`adr`, `adr-evaluate`, `artifact` and the three `diagram-*` skills),
with the `architect-*` and `adr-reviewer` agents, ship as
`dev10x-scoping`.
Install it where you file and scope tickets, estimate, or record
architecture decisions; it also brings `dev10x` with it.
Coding and scoping call each other's skills, but neither installs the
other: the edge is a declared soft dependency, so install
`dev10x-scoping` wherever your coding plays include ticket or scoping
steps.
The tracker MCP tools (`issue_*`, `milestone_*`, `triage_roster`) and
the spec-drift hook stay in `dev10x` under their old names:

```bash
claude plugin install dev10x-scoping@Dev10x-Guru
```

The coding skills ship as `dev10x-coding`: the `git` and `git-*`
skills, `ticket-branch`, the `gh-pr-*` skills and `gh-review-setup`,
`review`, `review-fix`, `request-review`, `slack-review-request`,
`gchat-review-request`, `work-on`, `fanout`, `foreman`,
`verify-acc-dod`, `py-test`, `py-test-flaky`, `py-mockito`, `py-uv`,
`investigate`, `qa-scope`, `release-notes`, `ide-normalize` and
`ci-review` — forty in all.
Install it wherever you commit, open PRs or run `work-on`; it brings
`dev10x` and `dev10x-tasks` with it, because `work-on` keeps its
terminal task open through the tasks plugin's `task-guard`.
The git and GitHub MCP tools (`push_safe`, `create_pr`,
`ci_check_status`, `merge_pr` and the rest) stay in `dev10x` under their
old names, so a `dev10x`-only install still lists them; the scripts
several of them run ship with `dev10x-coding`, so those tools need both
plugins:

```bash
claude plugin install dev10x-coding@Dev10x-Guru
```

Upgrading from a release where those skills were part of `dev10x`
and carried its `dev10x:` prefix: install each `dev10x-*` plugin whose
skills you used, then run `/dev10x:upgrade-cleanup` to rewrite the old
names in your configs.

Update to the latest version:

```bash
claude plugin update dev10x@Dev10x-Guru
```

The same marketplace also installs in **Claude Desktop** and on
claude.ai: add `Dev10x-Guru/Dev10x-Claude` as a marketplace URL.

### Upgrading from the `Dev10x` plugin id (GH-1499)

The plugin was renamed from `Dev10x` to kebab-case `dev10x`, because
claude.ai / Claude Desktop marketplace sync rejects any other name.
Claude Code treats that as a different plugin, so an existing install
does not pick up the rename on `update`. Switch once:

```bash
claude plugin marketplace update Dev10x-Guru
claude plugin uninstall dev10x@Dev10x-Guru
claude plugin install dev10x@Dev10x-Guru
```

Then run `/dev10x:upgrade-cleanup` so the permission catalog seeds the
new `Skill(dev10x:*)` and `mcp__plugin_dev10x_*` allow rules. Skills
are now invoked as `/dev10x:<name>`; rules still spelled
`mcp__plugin_dev10x_*` or `Skill(dev10x:*)` in your settings no longer
match anything and can be deleted.

### Install the develop (pre-release) version

To test the latest develop branch before it's released:

```bash
claude plugin marketplace remove Dev10x-Guru
claude plugin marketplace add Dev10x-Guru/dev10x-claude#develop
claude plugin install dev10x@Dev10x-Guru
```

Switch back to stable releases:

```bash
claude plugin marketplace remove Dev10x-Guru
claude plugin marketplace add Dev10x-Guru/dev10x-claude
claude plugin install dev10x@Dev10x-Guru
```

## Option B: Manual clone

This is a private repository. You need GitHub access granted through
the [Dev10x community](https://www.skool.com/Dev10x-1892). Once you
have access:

```bash
git clone git@github.com:Dev10x-Guru/dev10x-claude.git \
  ~/.claude/plugins/Dev10x
```

> **Using HTTPS?** Replace the URL with
> `https://github.com/Dev10x-Guru/dev10x-claude.git` and
> authenticate when prompted.

Register the local clone as a marketplace and install the plugin
from it:

```bash
claude plugin marketplace add ~/.claude/plugins/Dev10x
claude plugin install dev10x@Dev10x-Guru
```

Update manually with:

```bash
cd ~/.claude/plugins/Dev10x && git pull
claude plugin marketplace update Dev10x-Guru
```

## Option C: GitHub Action (automated PR review)

To run Dev10x automated PR review on a repository — independent of the
Claude Code plugin — install the **Dev10x PR Review** GitHub Action.
Add an `ANTHROPIC_API_KEY` secret and a workflow that references
`Dev10x-Guru/dev10x-claude@v1`. It reviews PRs on open and, on close,
proposes learned review rules via a rules-update PR for your approval.
See [GitHub Action install](github-action-install.md) for the full
install, permissions, troubleshooting, and cost guidance.

## Verify the installation

Start a new Claude Code session and check that skills are loaded:

```bash
claude
# Inside the session, type:
/dev10x-teach:skill-index
```

You should see a skills reference listing all available commands.

## Try without installing

Load the plugin for a single session without registering it:

```bash
claude --plugin-dir ~/.claude/plugins/Dev10x
```
